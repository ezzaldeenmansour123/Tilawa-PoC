# test_data — بيانات اختبار تركيبية (ليست تسجيلات حقيقية)

- `session_example.jsonl` — سجل جلسة **تركيبي** (أرقام مخترعة لأغراض اختبار
  أداة التقييم فقط): 4 أحداث موضع + 3 أخطاء مؤكدة + 1 غير متأكد + 1 تصحيح
  ذاتي. النتيجة المتوقعة من `tools/score_sessions.py`: TP=2، FP=1، FN=1،
  precision=recall=0.667، وسيط زمن التظليل 1100ms، P90 ‏1200ms، وسيط تأخير
  التأكيد 1000ms (الأقصى 2200ms). هذه الأرقام **ليست نتائج PoC** — هي
  إثبات أن الأداة تحسب ما تدّعي حسابه.
- `ground_truth_example.json` — ملف الحقيقة الأرضية المقابل (3 أخطاء
  مزروعة: محذوفة 1:2:3، مستبدلة 1:3:1، زائدة 1:4:2).

ملفات الحقيقة الأرضية الحقيقية تُكتب لكل جلسة فعلية قبل تنفيذها (النص
المطبوع + الأخطاء المزروعة)، وتُحفظ مع ملف JSONL بنفس `session_id`.
لا تُخترع بيانات تقييم أبداً.
